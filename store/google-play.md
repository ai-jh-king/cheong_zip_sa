# Google Play — 등록 메타데이터 템플릿

> Play Console > 앱 콘텐츠/스토어 등록정보. `[대괄호]`=운영자 입력. 글자수는 Play 제한.

## 스토어 등록정보
- **앱 이름**(최대 30자): `청주 부동산 시세 · 실거래가` *(예시 — 상표/유사명 확인)*
- **간단한 설명**(최대 80자):
  `청주 4개 구 아파트·빌라·오피스텔 실거래가, 청약, 매물, 대출 한도를 한 화면에.`
- **자세한 설명**(최대 4000자):
```
청주에서 집을 사거나 전·월세를 구할 때 꼭 필요한 정보를 한 곳에 모았습니다.

· 실거래가·시세: 상당·서원·흥덕·청원 4개 구의 아파트·오피스텔·빌라·단독다가구 실거래가와 시세 추이, 전세가율, 등락폭을 확인하세요. (자료: 국토교통부 실거래가)
· 청약·분양: 청주 분양·청약 일정과 경쟁률 정보.
· 매물: 사용자·중개사가 올린 매물을 거래유형·지역으로 검색.
· 내 대출 한도: 매매가·소득 기준으로 받을 수 있는 대출 한도와 월 상환액을 간단히 추정(참고용).
· 통근·예산 맞춤 찾기: 통근 시간이나 보유 예산으로 살 만한 단지를 찾아드려요.
· 관심 단지 알림: 신고가·가격 변동·청약 공고를 알림으로.

※ 실거래가는 신고 지연·정정·해제가 있을 수 있는 참고용 정보로 법적 효력이 없습니다.
※ 대출·시세 결과는 공시정보 기반 참고용 추정치이며, 실제 조건은 금융회사 심사로 달라집니다. 본 서비스는 금융자문업이 아닙니다.

문의: [지원 이메일]
```
- **앱 카테고리**: 라이프스타일 또는 금융 *(둘 중 택 — 부동산 정보 성격상 라이프스타일 권장)*
- **태그/키워드 검색어**: 청주, 부동산, 실거래가, 아파트 시세, 청약, 전세, 매물, 대출
- **연락처**: [지원 이메일] / [전화(선택)] / [웹사이트]
- **개인정보처리방침 URL**: `https://[도메인]/legal/privacy` *(앱 내용과 동일하게 웹 공개)*

## 콘텐츠 등급
- 설문 기반(폭력·성적 콘텐츠 없음 → 전체이용가 예상). 사용자 등록 매물에 텍스트가 있으므로 **사용자 생성 콘텐츠(UGC) '예'** 로 답하고 신고/차단 정책 안내.

## Data safety(데이터 보안) — ⚠️ 실제 동작으로 검증 필수
> 현재 코드 기준 추정. 대출 민감정보 저장 여부는 배포 설정에 따라 다름.

**수집·공유하는 데이터(추정)**
| 데이터 | 수집 | 공유 | 목적 | 비고 |
|---|---|---|---|---|
| 계정 식별자(카카오/네이버 로그인 uid·닉네임) | 예 | 아니오 | 계정 관리 | 소셜 로그인 시 |
| 기기 식별자(익명 device_id) | 예 | 아니오 | 비로그인 내 매물/알림 | 앱 생성 ID |
| 사용자 등록 매물(제목·가격·주소·사진 등) | 예 | 예(공개 게시) | 매물 게시 | 작성자가 공개로 등록 |
| 푸시 토큰(알림 구독) | 예 | 아니오 | 알림 발송 | 사용 시 |
| 금융정보(연소득·신용구간·부채 — 대출 계산) | **[확인]** | 아니오 | 대출 한도 추정 | 9.A 기본 stateless(미저장) — 저장 시 '예'로 표기·암호화·보유기간 명시 |
| 대략적 위치/주소 | **[확인]** | 아니오 | 통근·지도 | 사용자가 입력한 주소 기반인지 기기 위치 사용인지 확인 |

- **전송 중 암호화**: 예(HTTPS).
- **데이터 삭제 요청 경로 제공**: 예(개인정보처리방침에 명시 + [요청 경로]).
- ⚠️ 대출 금융정보를 '미저장(stateless)'으로 운영하면 수집='아니오 또는 처리 후 미보관'으로 정확히 기재. 저장한다면 암호화·보유기간·삭제수단을 반드시 라벨과 방침에 반영.

## 출시 트랙
- 비공개 테스트(내부) → 비공개 테스트(소수 베타·중개사) → 프로덕션. Android 먼저 권장.
- '새로운 기능'(변경사항): CHANGELOG 요약을 사용자용 문장으로.

> **v1.96~1.97 반영 필요**: ① 매물 **문의 연락처·내용**(사용자 입력) — 해당 매물 등록자에게 **전달(제3자 공유=예)**, 목적=앱 기능(문의 응대). ② **결제 정보**(결제 기능 활성 시) — 결제대행사 처리, 주문/거래 식별자만 보관. 위 데이터 안전성/개인정보 라벨 표에 두 항목을 추가하고 실제 동작과 일치시키세요.

> **계정 삭제 요건 충족(v1.106)**: 앱 내 ‘회원 탈퇴’(DELETE /auth/account) 제공 — Google Play 데이터 삭제/Apple 계정 삭제 정책 요건을 만족. 데이터 안전성·App Privacy의 ‘계정 삭제 가능’ 항목에 반영하고, 웹 삭제 경로(있으면)도 함께 기재.
