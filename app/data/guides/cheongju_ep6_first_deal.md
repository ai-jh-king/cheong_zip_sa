# 부동산 거래가 처음이라면 — 계약 전 확인 10가지

안녕하세요, 청집사입니다.

첫 계약은 누구나 떨립니다. 오늘은 매매든 전월세든 공통으로 통하는 **확인 목록 10가지**를 정리했습니다. 전부 제도적으로 확인 가능한 사실이고, 대부분 무료 또는 몇천 원이면 됩니다.

## 서류로 확인하는 것

**1. 등기부등본은 내가 직접 뗀다** — 인터넷등기소에서 700원. 계약 직전+잔금 직전 **두 번** 떼세요. 갑구(소유자)·을구(근저당) 확인. 상대가 보여주는 서류가 아니라 내가 뗀 최신본이 기준입니다.

**2. 소유자와 계약 상대가 같은 사람인지** — 등기부의 소유자와 신분증 대조. 대리인이면 위임장+인감증명서.

**3. 건축물대장 확인** — 정부24에서 무료. 위반건축물 여부, 실제 용도(주거용인지)를 봅니다. 근린생활시설을 주택처럼 파는 경우가 실제로 있습니다.

**4. 실거래가는 호가가 아니라 신고가로** — 부르는 값(호가)과 실제 거래된 값은 다릅니다. 국토부 실거래 공개시스템, 또는 저희 앱에서 단지별 실거래 중앙값을 바로 볼 수 있습니다.

## 돈 계산으로 확인하는 것

**5. 전세라면 전세가율** — 보증금 ÷ 매매시세. 저희 데이터 기준 청주 단지별로 **62~80%대까지 제각각**입니다. 높을수록 시세 하락 시 보증금 회수 여력이 줄어듭니다.

**6. (보증금+선순위 채권) ÷ 시세 계산** — 근저당이 있는 집이라면 반드시. 앱 더보기 → 전세 안전 진단에 넣으면 계산해 드립니다(공개 계산식, 판정 아님).

**7. 관리비·세금까지 월 부담으로** — 아파트 관리비, 재산세, (대출 시) 이자를 합쳐 월 기준으로. 매매가만 보면 부담을 과소평가하게 됩니다.

## 절차로 지키는 것

**8. 계약금은 등기부상 소유자 계좌로** — 다른 사람 계좌로 보내달라고 하면 멈추세요.

**9. 특약을 아까워하지 않기** — "잔금일까지 권리변동 없을 것", 전세면 "보증보험 가입 불가 시 계약 해제" 등. 구두 약속은 특약란에 적어야 효력이 분명해집니다.

**10. 전입신고+확정일자는 잔금 당일에** — 전월세 보증금 보호(대항력·우선변제권)의 기본. 주민센터나 정부24에서 잔금 당일 바로 처리하세요.
