# 대출·세금 계산 (services/loan.py, costs.py) — skills

## 고지(필수)
- 결과는 **공시정보 기반 참고용 추정치**. "승인/최저금리 보장" 등 단정 금지. 최종은 금융회사 상담.
- 본 서비스는 금융자문업·세무자문 아님(화면 상시 표기).

## 대출 한도 (loan.py)
- 실질 한도 = **min(LTV 한도, DSR 한도)**. binding(둘 중 낮은 쪽) 표기.
- 규제값은 `LOAN_RULES` 설정(청주=비규제 기준 LTV 0.70 / 생애최초 0.80 / DSR 0.40). 정책 변경 시 값만 수정.
- `consent=False` 또는 소득 미입력 → **간이모드**(LTV만). 개인정보 미저장(stateless).
- 월상환: 원리금균등/원금균등/만기일시 `simulate()`.

## 상품 카탈로그 (실연동 우선, 예시 폴백)
- 정책대출: `fetch_policy_products()`(HF, `HF_POLICY_API_URL` 설정 시) → 없으면 `POLICY_PRODUCTS`(예시).
- 은행: `fetch_loan_products()`(finlife, **주담대+전세**) → 없으면 `EXAMPLE_BANK`(예시).
- 서민금융: `fetch_seomin_products()`(서민금융 한눈에, `SEOMIN_API_URL` 설정 시) → 있으면 추천에 추가.
- `rates_live` 플래그로 "실시간 공시 vs 예시" 구분, 공시 기준일(`as_of`) 노출.

## 매수 부대비용 (costs.py) — 1주택 일반과세 기준
- 취득세율: 6억↓ 1% / 6~9억 1~3% 선형(`(억×2/3-3)/100`) / 9억↑ 3%.
- 생애최초 감면 최대 200만원(12억↓). 지방교육세=취득세의 10%. 농특세 0.2%(85㎡ 초과).
- 중개보수: `broker_brackets` 구간별 상한요율+한도.
- 법무·등기: `beopmu_estimate`(추정/설정값). 국민주택채권·실비는 별도 고지.
- 모든 요율은 `COST_RULES` 설정. **다주택 중과·감면 요건은 사례별** → 단정 금지.
- 대출 한도와 합산 → `total_cash_needed`(자기자본+부대비용), `total_cash_gap`.

## 검증
- 오프라인 단위테스트(예: 3억 생애최초 85㎡↓ → 부대비용 300만, 7.5억 취득 2.0%, 1.8억 중개 한도 80만)로 회귀 확인.
